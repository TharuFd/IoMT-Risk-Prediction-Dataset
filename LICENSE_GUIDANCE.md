# License and sharing guidance — read before making repo public

A dataset license has **not** been assigned automatically. The CSV may contain transformed or generated values informed by third-party source datasets; a downstream distribution license depends on verified source terms, ownership and institutional approvals.

1. Locate the original input data licenses and citations.
2. Verify whether derived datasets may be publicly redistributed.
3. Obtain agreement from all contributors / institution where applicable.
4. Choose and add a suitable license file only after those checks; code and data may need different licenses.
5. If uncertain, keep the repository **private** (GitHub supports private repositories), or publish only documentation/scripts until permissions are confirmed.

**No license file** is deliberately included; do not assume that the absence of a license grants reuse rights.
